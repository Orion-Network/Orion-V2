# Explanation
DandelionMMORPG is a Vanilla MMORPG themed server, created by [@NEXOmega](https://github.com/NEXOmega)
he is inspired by AresRPG Server, and a lot of other RPG-Themed games and Shows like Final Fantasy Tactic Advance, Overlord, Sword Art Online.

The team is currently restrited to [@NEXOmega](https://github.com/NEXOmega)

## The `Server`

Not released yet, but it's composed with a class system and a tree progression system, with treasures to find, resources to grind and dungeon to conquer.
A lot of Spell and a new Buffs system, with dangerous mobs and bosses.
